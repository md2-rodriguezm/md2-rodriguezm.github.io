## Commands

```bash
pnpm dev          # Start dev server on port 8080
pnpm build        # Production build
pnpm lint         # ESLint
pnpm test         # Run tests once (vitest)
pnpm test:watch   # Tests in watch mode
```

> The project uses **pnpm**. Do not use `npm` or `yarn`.

## Architecture

This is an architecture portfolio SPA (Vite + React 18 + TypeScript) for Martina D. Rodríguez Marrero, deployed to GitHub Pages.

### Routing

All routes are defined in [`src/App.tsx`](src/App.tsx) via React Router v6. Every page component is **lazy-loaded** with `React.lazy()` wrapped in `<Suspense>`. Add new routes above the catch-all `*` route.

| Route | Page |
|---|---|
| `/` | Index (hero + CV/portfolio download) |
| `/projects` | Projects grid |
| `/project/:id` | Project detail (dynamic, driven by `id` field in project data) |
| `/research` | Research papers |
| `/cross-cultural` | Cross-cultural work |
| `/representation` | Representation work |
| `/sketches` | Sketches & technical drawings |
| `/job-application` | Job application page |

### Project Data

All portfolio projects live in [`src/data/projects.ts`](src/data/projects.ts) as the `projects` array. Adding or editing a project means editing this file. The `id` field maps to the `/project/:id` URL. Images are imported directly from `src/assets/project_N/`.

The `Project` interface requires: `id`, `title`, `subtitle`, `label`, `category`, `year`, `location`, `description`, `image`, `gallery`, `status`, `details`. Optional: `videoUrl`.

### BIM Viewer (Speckle)

The `@speckle/viewer` 3D BIM viewer lives in [`src/components/speckle/`](src/components/speckle/). It is **lazy-loaded** and only renders for the project with `id === 'hospital'` in `ProjectDetail.tsx`. The viewer state and Speckle SDK setup are encapsulated in `useSpeckleViewer.ts`.

### Assets

Images are stored in `src/assets/` organized by project (`project_1/`, `project_2/`, `project_3/`, `sketches/`, `cross-cultural/`, `representation/`). Vite is configured to handle `.JPG`, `.jpg`, `.png`, `.heic`, `.HEIC` extensions. PDFs (`MDRM_Portfolio.pdf`, `Martina_D_Rodriguez_Marrero_CV.pdf`) live in `public/` and are referenced via `import.meta.env.BASE_URL`.

## Design System

The site uses a **dark architecture palette** (near-black background, white text) with a **bronze/copper accent** (`--primary: hsl(28 56% 46%)`). All border radii are `0px` (sharp corners). Fonts: **Space Grotesk** (headings) and **Inter** (body).

Custom Tailwind utility classes defined in [`src/index.css`](src/index.css):

- **Typography:** `heading-xl`, `heading-lg`, `heading-md`, `body-lg`, `body-md`, `caption`
- **Layout:** `section-container` (max-width wrapper with horizontal padding), `section-py` (vertical section spacing)
- **Components:** `project-card`, `image-container`, `focus-ring`, `accent-underline`, `nav-blur`

Custom Tailwind colors: `background-deep`, `border-subtle`. Use these instead of arbitrary values.

## shadcn/ui

UI primitives are in `src/components/ui/` (auto-generated by shadcn). Do not edit these files manually. Add new shadcn components via `pnpm dlx shadcn@latest add <component>`.

## Path Alias

`@/` maps to `src/`. Use it for all imports within `src/`.
